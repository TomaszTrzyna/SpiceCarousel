# SpiceCarousel
Smart rotating spice storage system powered by ESP32 and C++

# SpiceCarousel

### Inteligentny, obrotowy magazyn przypraw

Projekt realizowany w ramach przedmiotu **Zaawansowane programowanie obiektowe**.

## Opis projektu

SpiceCarousel to inteligentny system przechowywania i organizowania przypraw, oparty na obrotowej karuzeli sterowanej mikrokontrolerem ESP32.

Użytkownik wybiera przyprawę za pomocą panelu sterowania, a urządzenie automatycznie ustawia odpowiedni pojemnik w miejscu odbioru i podświetla go.

System umożliwia zarządzanie przyprawami, zapamiętywanie ich lokalizacji oraz monitorowanie dostępności produktów.

## Planowane funkcjonalności

- Automatyczny obrót karuzeli do wybranej przyprawy.
- Zapamiętywanie lokalizacji produktów w pamięci nieulotnej.
- Dodawanie, usuwanie i edycja przypraw.
- Podświetlanie wybranego pojemnika.
- Wykrywanie wyjęcia i odstawienia pojemnika.
- Informowanie o niskim stanie zapasów.
- Interfejs użytkownika umożliwiający wybór przypraw.

## Technologie

- **C++** – programowanie obiektowe i logika systemu.
- **ESP32** – sterowanie urządzeniem.
- **PlatformIO** – kompilacja i zarządzanie projektem.
- **GitHub Actions** – automatyczne testowanie i budowanie wydań.
- **Druk 3D** – konstrukcja mechaniczna karuzeli.

## Architektura

Projekt będzie wykorzystywał programowanie obiektowe, w szczególności hermetyzację, abstrakcję, kompozycję i polimorfizm.

Logika aplikacji zostanie oddzielona od obsługi sprzętu, co umożliwi jej automatyczne testowanie na komputerze.
